# FurryBotch 🐾

FurryBotch é um bot Discord completo com suporte a automações, moderação, comandos slash e integração MCP.

## 🚀 Como Começar

### Pré-requisitos
- [Node.js](https://nodejs.org/) ou [Bun](https://bun.sh/)
- Discord Bot Token configurado

### Configuração
1. Copie o arquivo `.env.example` para `.env`:
   ```bash
   cp .env.example .env
   ```
2. Preencha as credenciais no `.env`:
   ```env
   DISCORD_TOKEN=seu_token_aqui
   CLIENT_ID=1562259079416778772
   ```

3. Instale as dependências:
   ```bash
   npm install
   # ou
   bun install
   ```

4. Execute o bot:
   ```bash
   npm start
   # ou
   bun run dev
   ```

## 🛠️ Tecnologias
- Discord.js / MCP Protocol
- TypeScript / JavaScript
